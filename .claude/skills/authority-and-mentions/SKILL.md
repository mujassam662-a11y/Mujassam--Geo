# authority-and-mentions

## Scoring (1-5 each, keep >= 14/20)
relevance to 3D printing/engineering in Egypt · credibility · audience value · realistic outcome.

## Procedure
1. Track existing mentions (URL, date, context, link yes/no).
2. List opportunities: university project resources, fab labs/maker spaces, CAD educators, directories, suppliers, design communities, publications.
3. Draft message in Arabic: who we are (approved facts only), concrete value, evidence; save under reports/outreach/ as draft.
4. Sending requires approval + verified identity (skill: email-identity-verification).

## Output
`[{target, url, type, scores:{...}, total, angle, draft_path, status:"draft"}]`
