# geo-report-generation

## Commands
`python -m geo report daily|weekly|monthly` -> `reports/<cadence>/<date>.md`

## Content standard
Integration status · AI visibility (n + small-sample warnings, manual vs proxy separated) · search demand · behaviour & funnel measurability ·
fact conflicts · top backlog · (monthly) experiments, margin, period comparison · execution log.
Labels: [مُلاحَظ] observed, [محسوب] computed, [فرضية] hypothesis. Missing data is stated, never filled.
