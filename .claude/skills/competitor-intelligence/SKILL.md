# competitor-intelligence

## Procedure
1. Search (ar + en): "طباعة ثلاثية الأبعاد مصر", "3D printing service Egypt", "طباعة 3D اونلاين", plus competitors cited in AI answers.
2. Verify activity; record in `data/competitors.json` with sources and fetch dates.
3. Compare: materials/tech, build volume, price list, quote flow, file formats, content depth, external references, AI citations.
4. Opportunities = where Mujassam has a verified advantage (e.g. public per-gram price list) that is not yet clearly stated or cited.

## Output
Comparison table + opportunity list, each cell with a source URL; unknown = "not published".
